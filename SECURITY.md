# Security policy

## Supported version

Only the version live at https://lines.bortnik.org is supported. It is rebuilt from `main` on every merge.

## Reporting a vulnerability

Please report security problems privately: open this repository's [Security and quality](https://github.com/timbortnik/lines/security) tab and choose **Report a vulnerability**. Please don't open a public issue for them.

## Scope

The game is a static website with no backend. It has no accounts and sends nothing to a server; anything it stores stays in your browser.
